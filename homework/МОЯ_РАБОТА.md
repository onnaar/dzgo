# Сервис уведомлений

Автор: Александров Онар

## Что делает программа

сервис отправляет пуш/емаил уведомления по заданному идентификатору девайса/почте
в метод Send передается объект и текст сообщения, который затем отправится

## Как запустить

всё из корневого каталога

запуск программы: go run ./cmd/notify/main.go

запуск тестов: go test (-v) ./practice

версия go 1.22+

## Проверенные случаи


|случай | результат|
|---|---|
|успех|вывод соо об успехе + msg записан в слайс сообщений уведомителя|
|пустой текст|ловится ошибка пуст сообщения + msg НЕ записан в слайс сообщений уведомителя|
|отсутсвие поля|ловится ошибка типа *SendError + msg НЕ записан в слайс сообщений уведомителя|
|паника канала|ловится ошибка переделанная из паники с сообщением "драйвер канала повреждён", код продолжает выполнение и следующий уведомитель получает свое сообщ планово верно|




## Обработка ошибок

Dispatch осуществляет рассылку но стопается при первой же ошибке, а SafeDispatch
допом защищает от паники и складывает все ошибочки в слайсик.

errors.Is - для определения причины ошибки(в пустом сообщении и вызове паники)

errors.As - при разборе ошибок с неверными полями,

recover находится вокруг отдельного вызова чтобы рассылка могла продолжиться даже несмотря на вызванную панику(не завершаться после ее возникновения)
, иначе recover бы возвращал работоспособность, но прерывал весь процесс на шаге с паникой.
